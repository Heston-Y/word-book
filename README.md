# word-book

브라우저에서 바로 실행되는 영어 단어 공부 앱입니다. 설치나 빌드 없이 `index.html`을 열면 됩니다.

## 기능

- **단어장**: 단어·뜻·예문 추가/수정/삭제, 검색, 필터(복습할 단어·학습 중·외운 단어·중요), ★ 중요 표시, 🔊 발음 듣기
- **플래시카드**: 카드를 뒤집어 확인하고 "알아요/몰라요" 체크 (단축키: Space 뒤집기, ←/→ 채점)
- **퀴즈**: 객관식(영어→뜻, 뜻→영어, 숫자키 1~4로 선택), 주관식 철자 쓰기
- **간격 반복 학습**: 라이트너 방식으로 맞히면 복습 간격이 1→2→4→7→15일로 늘어나고, 틀리면 처음부터 다시
- **통계**: 전체/외운 단어 수, 정답률, 최근 7일 학습량, 단계별 분포, 자주 틀리는 단어
- **가져오기/내보내기**: `단어, 뜻, 예문` 형식 텍스트 일괄 입력, JSON 백업/복원

데이터는 브라우저 `localStorage`에 저장됩니다.

## 실행

```sh
# 그냥 파일을 열거나
open index.html
# 로컬 서버로 실행
python3 -m http.server 8000
```
